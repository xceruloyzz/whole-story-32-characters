Entry for the [Tell a Whole Story in 32 Characters](https://make.fun/c/u-xvader-tell-a-whole-story-in-32-characters-f86dd978) bounty on make.fun — a single Wi-Fi network name, 32 characters or fewer, that lands a joke and implies a story in the few words a passer-by sees in a phone's network list.

## The entry

> The Neighbors Heard Everything

30 characters. `main.py` writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`) — directly to the final file, no temp files, no trailing newline.

## Run

```sh
python3 main.py
```
